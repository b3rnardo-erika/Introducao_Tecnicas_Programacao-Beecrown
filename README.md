# Anotações - Programação em C

## Observações

### Como rodar os códigos

Para compilar um arquivo C:

```bash
gcc nome_arquivo.c -o nome_arquivo
./nome_arquivo
```

### Objetivo

* Praticar a resolução de pequenas questões do Beecrowd, fornecidas pelo professor, utilizando a linguagem C, com o objetivo de desenvolver a lógica de programação, aprimorar os conhecimentos sobre a linguagem e reforçar os conteúdos estudados em sala de aula.
